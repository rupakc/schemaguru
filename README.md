# SchemaGuru

Automated schema intelligence for data warehouses: discover the catalog, measure what
joins and what values really occur, derive safe join paths, draft meaning with an LLM
(humans always win through YAML overlays), and serve a question-scoped, token-budgeted
view to any agent.

> Status: pre-alpha, under construction. Measurement is delegated to
> [FactLang](https://github.com/rupakc/factlang).

MIT licensed. See `docs/specs/` for the design.
