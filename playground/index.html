    Playground¶

    This is the real SchemaGuru library, the wheel built from this site's commit, running in your browser through Pyodide. It serves a small knowledge store of the shop fixture that was crawled, measured and lineage-parsed when the site was built. Nothing you type leaves the page, and no warehouse is connected: the only downloads are Python itself from the Pyodide CDN and this site's own files, a few megabytes on the first visit and cached afterwards.

    Python starts when you pick a tab or scroll here.

    This browser cannot run the playground. It needs WebAssembly, which is missing or turned off here.

    Everything on this page also runs locally: start with Getting started, or read the guides on scoping, join paths, lineage, PII and value masking and overlays.

    Ask a question about the shop. SchemaGuru scopes the catalog to it and renders the view an agent would get, within a 4,000-token budget.

      What you are looking at¶
      

        

      • Ask a question calls guru.context(question, profile=…): the same scoped view your agent
  gets. Switch profiles to see how a planner, verifier or router view differs. See
  Scoping and Rendering views.
        • 

      • Join path calls the find_join_path tool. SQL snippets for a path appear in the context
  view of a question that needs it. See Join graph and path search.
        • 

      • Lineage calls the lineage tool. See Lineage.
        • 

      • Privacy runs the value-masking sweep. See PII and value masking.
        • 

      • Override loads your YAML as a human overlay on top of the site's own. See
  Overlays.
        • 

      

      To run SchemaGuru on your own warehouse, follow Getting started.
